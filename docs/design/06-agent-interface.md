# 6. Agent interface and file schemas

Normative proposed interface v1. All commands here are **design contracts**, not available software. See [examples](examples/README.md) and the structural [JSON Schema](command-schema.json).

## Decision: typed JSON jobs, small CLI envelope

| Approach | Token/generation behavior | Parsing, recovery and discovery | Decision |
|---|---|---|---|
| Typed JSON operations | Repeated keys cost tokens; compact grids, palette symbols and target arrays amortize them. LLM structured-output facilities can generate it without a provider SDK. | One parser serves requests/manifests/results; JSON Pointer errors, ordinary arrays and standard schemas. No substitution/loop syntax. | Select; measure actual model-specific token cost rather than assume JSON is cheapest. |
| Line recipe grammar | Often fewer punctuation tokens for scalar edits; quoting, nesting, owner order and custom repetition still need teaching. | Adds a second syntax/parser/escaping contract, restricted snapshot mode and schema translation. | Discard: no measured advantage justifies this language. |
| JSON plus bespoke compact statements | Convenient for some hand-written edits, but creates two generation/escaping paths and equivalence tests. | Can diverge in defaults/errors; adds no graphics capability. | Reject until evidence demonstrates a material workflow gain. |

CLI flags only select files, limits and read-only queries. They do not form a second drawing language. A recipe means a versioned JSON job. Reusable templates are job files edited/generated by the host; no engine parameters, includes, loops, expressions, macros, wildcard selectors or embedded code. Explicit operation/target arrays batch work in one invocation. An external host may generate requests by any means; it is not a raipixel runtime dependency.

## Process surface

```text
raipixel help [OPERATION] [--json]
raipixel schema [OPERATION]
raipixel version [--json]
raipixel run JOB.json --out NEW_DIRECTORY [--project SNAPSHOT] [--dry-run]
raipixel inspect SNAPSHOT [--query QUERY.json]
raipixel validate SNAPSHOT [--query QUERY.json]
raipixel export SNAPSHOT EXPORTS.json --out NEW_DIRECTORY [--dry-run]
```

A file argument `-` reads one bounded JSON document from stdin; at most one stdin document per invocation. `run` without project starts empty. All machine actions output JSON. Help/version are text unless --json; schema is always JSON. Global flags `--max-memory BYTES`, `--max-work UNITS`, `--max-input BYTES` can only lower domain ceilings. No environment config or implicit scanning. Imports resolve relative to the containing request/query file, or cwd for stdin; snapshot-internal image paths resolve only under that snapshot. Output is an explicit CLI path.

`help --json` lists operation names, purpose, priority, **implemented capability status in that binary**, mutability, keys/types/defaults, constraints, error codes and feature IDs. `schema` emits the corresponding Draft 2020-12 JSON Schema, matching the versioned operation descriptors; the executable does not need a general JSON Schema validator. The checked-in schema describes proposed Foundation/Core syntax, not a claim that those features exist. Unsupported planned operations/fields must return E_CAPABILITY with the actual supported set.

`run` stages a complete snapshot plus requested artifacts under `artifacts/NAME/`. `export` reads a snapshot and publishes artifacts only; EXPORTS.json is `{interface:1,semantics:"1.0",exports:[...]}` in valid JSON syntax. `inspect`/`validate` never create files. Dry-run executes actual decode/edit/render/validation and calculates outputs but creates no directories; it does not forecast disk/rename success. Every output directory must be absent; no force/in-place overwrite.

## JSON profile and job envelope

Implement RFC 8259 UTF-8 parsing/emission, including escapes, surrogate pairs and the complete number grammar. Reject duplicate decoded keys, unpaired surrogates and BOM in this application profile. Convert numeric fields exactly to integral values within their declared ranges; no floating-point graphics or silent rounding. Bound nesting, token length, strings/counts and work. Unknown keys/versions/operations fail; never silently ignore misspellings. Optional fields use only documented defaults. JSON null is allowed only for explicitly nullable references. Color inputs are `#RRGGBB`, `#RRGGBBAA` or `@PALETTE/ENTRY`; RGB resolves alpha=255. Palette definitions themselves use RGB literals.

```json
{"interface":1,"semantics":"1.0","ops":[],"checks":["structure"],"exports":[]}
```

interface, semantics and ops are required. checks defaults to [structure], exports to []. Structural validation always runs. Other requested checks block publication on failure. Export additionally enforces dimensions, alpha/palette/style, bounds and selection-specific requirements; inspection previews (contact/onion/diff) validate underlying structure/bounds, not palette membership of overlay colors. Intermediate invalid technical state may be saved without a game export if explicitly limited to structural checks; no silent correction occurs. All operations execute in array order, but exports/reports observe final state.

## Typed operation registry

`!` means required. F=Foundation, C=Core; later-only algorithms have no executable syntax yet. All operation objects also require `op`. Names/references/limits follow the domain. The schema enumerates types; prose below owns cross-field rules.

Common pixel-write fields W: `targets!` array of cel refs, `region` rect, `mask` cel ref, `clip=false`. mask and more than one target are Core. Mode is copy/over only when declared. Source reads are frozen before writing any target. Color tables must resolve before mutation. No duplicate targets, mappings, owners or palette names.

| Operation | Tier | Fields and defaults |
|---|---|---|
| asset.create | F | name!, size!, pivot=[0,0], palette/style nullable name (default null; style Core) |
| asset.clone | C | source! asset name, name! new name; copies all state, retargets internal refs |
| asset.set | F/C | asset!, at least one of pivot, palette or style; null clears reference; style Core |
| layer.create | F | asset!, name!, visible=true, opacity=255; append bottom-to-top |
| layer.set | F/C | target! asset/layer; at least one of visible, opacity, order; order is Core final zero-based index after removal |
| frame.create | F/C | asset!, name!, duration_ms=100; source optional same-asset frame name (Core); omitted duration uses source timing when cloning. Multiple frames are Core. |
| frame.set | C | target! asset/frame; at least one of duration_ms, order; same final-index rule |
| cel.create | F | target!, size defaults canvas, offset=[0,0], source optional cel ref, replace=false. With source, omitted size/offset use source; size override forbidden. |
| cel.offset | F | targets!, at! integer offset; absolute placement, no resampling |
| png.import | F | target!, file!, offset=[0,0], replace=false; existing owners required, imported size retained |
| grid | F | W, at=[0,0], rows! nonempty equal-width strings, symbols! object mapping one-character keys to colors, skip optional single character, mode=copy |
| draw | F/C | W, shape! pixel/line/rect/ellipse/polygon, color!, mode=copy; pixel at!, line points! exactly two, rect/ellipse rect!, polygon points!; filled=true for closed shapes; ellipse/polygon Core |
| fill | F | W, at!, color!, mode=copy; pattern-source fill Advanced, not accepted by v1 |
| stamp | F/C | W, source! cel, at=[0,0], rect defaults full source, mode=over; batching/masks Core |
| transform | C | targets!, kind! flip-x/flip-y/rotate-90/rotate-180/rotate-270/scale/reduce/crop; scale factor!, reduce grid! and phase=[0,0], crop rect!; other kind-specific fields forbidden |
| palette.set | F | name!, entries! [{name,rgb},...], replace=false |
| palette.extract | F | source! cel, name!, max_colors=256; exact extraction only; destination must be absent |
| palette.map | F/C | W, pairs! [[FROM,TO],...], preserve_alpha=true; RGB literals required when true, RGBA interpretations when false |
| palette.quantize | C | W, palette!, dither="none" only; alpha unchanged; Bayer4 is Advanced |
| alpha | F/C | W, kind! key/threshold; key color! and match=rgb (rgb/rgba), threshold threshold! (0–255); unrelated fields forbidden |
| mask.create | C | source!, target!, kind=alpha (alpha/color), threshold=1 for alpha (1–255), color! and match=rgb/rgba for color, replace=false; source size/offset copied |
| noise | C | W, seed! 16-hex-character string, colors! array, density! 0–1000 |
| anchor.set | C | targets! frame refs, name!, at!; existing named anchor replaced deliberately |
| clip.set | C | asset!, name!, frames! array of same-asset frame names, direction="none", playback=forward, repeat=0, replace=false |
| style.set | C | name!, size optional, palette optional name, alpha=any, anchors=[], nonempty=false, replace=false |
| component.transfer | C | project! snapshot path, source! asset, name! destination; only referenced palette/style dependencies |
| sheet.import | C | asset!, layer!, file!, size! equal canvas, names! nonempty unique frame names, durations_ms optional aligned list (default100), columns!, padding=0; no replacement of existing frames |
| meta.set | F | scope! project/asset/frame; target! for asset/frame only; key! name, value! string; replace=false |
| object.delete | C | kind! asset/layer/frame/cel/clip/anchor/palette/style/meta; target! typed name/ref except project metadata; scope/key required for meta; cascade=false allowed only for layer |

A grid symbol and skip must be printable ASCII; skip cannot also be in symbols. Rows may use skip but every other character must be mapped. A transparent mapping writes all four samples; skip preserves them. Valid source rects must lie entirely inside the source. region must be inside the target. Masks are canonical binary images; arbitrary alpha masks fail E_MASK rather than silently threshold. create/transfer do not implicitly create owners. Setting existing fields is idempotent, but over/noise/fill/replay may not be; replay creation jobs on fresh input.

## Export requests and read-only queries

Each ExportSpec has name!, kind!, targets! frame refs, scale=1, allow_clip=false, components=false. Names uniquely select generated artifact directories. Kinds: `frame` (one target, Foundation); `sheet/contact/frames` (nonempty unique targets, Core); `diff` (two equal-size targets, Core); `onion` (exactly three equal-size ordered prev/current/next, Core). Equal targets are allowed for onion/diff only.

sheet/contact use columns=1, padding=0. Only sheet allows extrude=0 and requires extrude<=padding. `clips=[]` qualified asset/clip refs and components=true are allowed only for frame/sheet/frames/contact; selected clips must reference exported frames. components exports each stored cel with logical/scaled offset, visibility and opacity in metadata, including hidden layers. Frame images use image.png, sheets/contact sheet.png, frames numbered PNGs, diagnostic previews image.png. Sidecar is metadata.json; diff adds stats.json. No output paths inside requests; filenames use stable numeric indices. Reusable export requests replace a separate persisted preset subsystem.

Inspect query keys: `target` optional asset/frame or cel; `region` optional rect; `pixels=false`; `symbols=false`; `histogram_limit=16` (1–256); `against` optional `{project,target}` comparison of the same target type and dimensions. No target returns project names/counts; target returns structure and raster stats. Region requires target and is image-local for a cel, canvas-local for a frame. Raw pixels/symbols require a region <=4096 pixels; symbols assigns stable characters by RGBA order, returning a legend (fails E_LIMIT if >94 unique samples; pixels remains available). Stats include pixel count, visible/zero/partial/opaque counts, visible bbox or null, unique_colors, a histogram sorted by descending count then RGBA and capped at histogram_limit, histogram_truncated, and CRC32 labeled non-cryptographic. The counts include transparent samples; histogram counts sum to pixel count only when untruncated. Symbol legends use characters33–126 assigned by RGBA order; legends are independent of histogram truncation. Against returns changed sample count, changed visible-color/alpha counts and change bbox for selected region plus unrelated-state comparison flags; it never judges anatomy.

Validate query keys: optional asset name and checks array. Names: structure, dimensions, palette, alpha, bounds, animation, registration, metadata. Default structure/dimensions/palette/alpha/bounds/metadata plus animation for multi-frame assets. Registration compares required style anchors, or common anchor names with a coverage warning if none are required. Export checks sheet geometry/clips intrinsically; there is no standalone sheet check without an export request. Advanced tile checks will be added with their feature. Return every requested diagnostic, sorted by asset/layer/frame/check/coordinate; never silently fix.

## Success, errors and recovery

Common result envelope: schema=1, ok, semantics, action, diagnostics, result. Each diagnostic includes severity, code, message, details object, hint, plus target/pointer when applicable. Failure envelope uses schema/ok=false/action/error; error adds zero-based op_index and JSON Pointer when available. Messages may evolve; codes and typed details are stable within interface major. Never echo arbitrary input artwork or full file contents.

```json
{"schema":1,"ok":false,"action":"run","error":{"code":"E_BOUNDS","op_index":4,"pointer":"/ops/4/rect","target":"hero/armor/walk1","message":"Rectangle exceeds cel width","details":{"size":[32,32],"rect":[30,0,4,4]},"hint":"Use an in-bounds rectangle or explicitly request clip:true"}}
```

run result: operations, per-target changes (write_events, changed_write_events, clipped_candidates, changed_bbox), work_units, snapshot path, artifacts [{path,bytes}], fidelity [{name,format,preserved,omitted,converted,unsupported}] and publication=committed. Each fidelity item describes a requested export by name; its four semantic-field lists are required, including empty lists. Native snapshots preserve full state; raster exports explicitly list omitted layers/edit structure and unsupported color-profile handling in diagnostics. Repeated changed writes count repeatedly; distinct final differences come from inspect against. Metadata/offset changes are separate state_changes, not pixels. Dry-run returns publication=planned, destination and calculated outputs without creating files. validate always returns its report on stdout, including ok=false and exit3; report fields passed/checks/error_count/warning_count, diagnostics once at top-level. Other failures use stderr JSON with stdout empty. Success stderr is empty; warnings stay in diagnostics. Help/schema output must be filtered by operation so an agent need not load the entire catalogue.

| Exit | Meaning / error families |
|---|---|
| 0 | Successful action, including no-op and dry-run |
| 2 | E_USAGE, E_JSON, E_ARGUMENT, E_REFERENCE, E_EXISTS, E_CONFLICT, E_VERSION, E_CAPABILITY |
| 3 | E_BOUNDS, E_MASK, E_STYLE, E_PALETTE_EMPTY/TOO_MANY, E_ANIMATION, E_SHEET, E_PROJECT; other technical validation diagnostics |
| 4 | E_IO, E_OUTPUT, E_PNG_SIGNATURE/CHUNK/CRC/FILTER/DEFLATE/ADLER, E_UNSUPPORTED_DEPTH/ANIMATION/PNG |
| 5 | E_LIMIT, E_ALLOC, including bounded parser/decoder work exhaustion |
| 70 | E_INTERNAL: detected implementation invariant defect |

Before-publication failure leaves no destination and no source change. The [publication contract](04-architecture.md) governs rename races, cleanup, power loss and reporting failures after commit. A broken output channel can truncate JSON; after a transport failure check destination before retry. Inspect and validate have no publication boundary.

## Native manifest and export metadata

Native `project.json` has exactly format="raipixel-project", version=1, semantics="1.0", images, palettes, styles, assets, metadata. All collections are arrays except metadata (string-value object); names unique within owner. Required empty arrays/objects are emitted. Image entries `{id,file,size}` bind numeric IDs to standard RGBA8 PNGs and declared dimensions. Native surfaces MUST be type6 8-bit, noninterlaced; loader supports the same independently implemented PNG machinery. IDs have form i000000 (six decimal digits; limits cap image count) and map to the matching images/000000.png basename. Declared size MUST equal decoded IHDR dimensions. Unreferenced surface entries warn and disappear on a new save; duplicate IDs/files or missing refs fail.

Palette entries use `{name,entries:[{name,rgb}]}`. Style entries use `{name,size:null|[w,h],palette:null|name,alpha,anchors:[name,...],nonempty}`. Asset entries require name,size,pivot,palette,style,layers,frames,clips,metadata. Layers require name,visible,opacity. Frames require name,duration_ms,cels,anchors,metadata. Cels require layer,image,offset; one per layer/frame. Anchors map names to [x,y]. Clips require name,frames,direction,playback,repeat. No implicit defaults on load; unknown fields fail E_VERSION with a migration hint. Manifest strings never execute or import source paths. Reference checks run after loading all declared structures; no owner ordering language is needed. Format-major changes protect readers when persisted semantics change; recipes never serve as snapshots.

```json
{"format":"raipixel-project","version":1,"semantics":"1.0","images":[{"id":"i000000","file":"images/000000.png","size":[1,1]}],"palettes":[],"styles":[],"assets":[{"name":"dot","size":[1,1],"pivot":[0,0],"palette":null,"style":null,"layers":[{"name":"ink","visible":true,"opacity":255}],"frames":[{"name":"base","duration_ms":100,"cels":[{"layer":"ink","image":"i000000","offset":[0,0]}],"anchors":{},"metadata":{}}],"clips":[],"metadata":{}}],"metadata":{}}
```

This shape example requires the referenced image; it is not a standalone test project. Every current Core field, including hidden layers/samples, timing, registration, palettes/styles and reference relationships, MUST round-trip. Unknown metadata keys remain inert strings and are preserved. No clocks, absolute source paths or machine identity are inserted by default. JSON output is deterministic: schema-order fields, sorted named maps, stable meaningful arrays, decimal integer numbers, uppercase hex colors, required escaping, UTF-8, terminal newline. This is a project convention, not an assertion of RFC canonical-JSON conformance.

Game metadata requires schema=1, semantics, origin="top-left", alpha_mode="straight", color_policy="unmanaged-encoded-rgb8", images [{file,width,height}], frames [{asset,frame,index,image,rect,canvas,logical_canvas,pivot,logical_pivot,anchors,logical_anchors,duration_ms}], clips [{asset,name,direction,playback,repeat,sequence}], palettes/styles used, and components (empty unless requested). Image is a zero-based images index. Rect/pivot/canvas/anchors are output pixels; logical fields retain source units. Frame index is zero-based export order. Clip sequence is the original named frame list mapped to indices; playback/repeat retain their defined semantics. Component entries require asset/frame/layer/image, offset/logical_offset, visible, opacity. Components refer to uncomposited stored cel samples, not the rendered sheet; scaling replicates pixels exactly. Padding/extrusion never changes registration. A decoder can reconstruct placements but metadata is not an automatic native-project importer.

This game schema is explicitly raipixel-owned; generic JSON support does not make it directly importable by every engine. Prove one independent consumer and prefer an existing documented profile when a concrete target requires it. Do not invent editor-format compatibility or unnecessary tile-map conventions.

Breaking request/schema changes bump interface/project/export major as applicable. Algorithm output changes bump engine semantics; writer representation changes are reported by version/help and fixture updates. Unknown required versions fail with supported alternatives. Explicit migrations are future work when a real second version exists; no migration framework now.
