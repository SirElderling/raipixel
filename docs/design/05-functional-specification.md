# 5. Functional specification

Normative selected-release behavior. All features inherit domain limits, checked arithmetic, canonical transparent pixels, ordered errors and job publication rules. In the table, “unchanged” means no committed state/output on failure. E codes are defined in the interface. Each feature must be accepted independently before it is claimed as delivered.

### Exact raster decisions

Line uses integer Bresenham with canonical endpoints: swap to lexicographic (x,y) order first, initial dx=abs(x1-x0), dy=-abs(y1-y0), err=dx+dy, e2=2*err; update x when e2>=dy, y when e2<=dx. Include both endpoints and evaluate both conditions against the saved e2. Reversal therefore renders identical coverage. This is a discrete straight-line operation; interactive freehand stroke corner cleanup is out of scope.

Filled rect covers its half-open rectangle; outline covers its edge pixels. Filled ellipse inside rect [rx,ry,w,h] selects pixel (x,y) when `(2*x+1-2*rx-w)^2*h^2 + (2*y+1-2*ry-h)^2*w^2 <= w^2*h^2`, calculated in i128. Outline is the set of inside pixels with at least one four-neighbor outside, treating outside the bounding rectangle as outside. This prioritizes one shared coverage predicate over a separate optimized midpoint algorithm; the work limit controls large bounds.

Polygon requires 3..4096 vertices, no repeated terminal vertex; filled coverage uses pixel centers and even-odd crossings with a half-open y interval (lower endpoint included, upper excluded), exact rational comparisons in i128; self-intersections follow even-odd semantics. Outline rasterizes each edge with F02's line rule. Geometry outside the image still needs clip=true. A mask is true when its pixel alpha is nonzero. Region/mask coordinates are target image-local and mask dimensions must equal target dimensions.

Bayer4 matrix in row-major order is `[0,8,2,10;12,4,14,6;3,11,1,9;15,7,13,5]`. For closest colors c0 and c1, d=c1-c0, `num=clamp(dot(pixel-c0,d),0,dot(d,d))`, den=dot(d,d); choose c1 when `32*num > (2*B[x mod 4,y mod 4]+1)*den`, otherwise c0. If den=0 choose c0. Phase is asset-space `(image coordinate + cel offset + supplied phase)` with Euclidean modulo. All math integer; alpha treated independently. It is an economical ordered-dither approximation, not perceptual quantization.

Texture uses wrapping u64 arithmetic. `mix(z)` performs `z=(z xor (z>>30))*0xbf58476d1ce4e5b9`, then `z=(z xor (z>>27))*0x94d049bb133111eb`, then `z xor (z>>31)`. For image-local nonnegative x,y: `h=mix(seed + x*0x9e3779b97f4a7c15 + y*0xbf58476d1ce4e5b9)`. Choose pixel if h%1000<density; color index is mix(h)%color_count. This is not cryptographic randomness; modulo bias is accepted. Numeric behavior is pinned by semantics 1.0.

### Exact sheet/export contract

Preset stores name, kind (frame/sheet/frames/contact/onion/diff/map/seam/palette), qualified selection, columns, padding, extrusion, integer scale, png mode, allow-clip and optional components. Required keys depend on kind, specified in the interface. A preset contains no absolute output path and is resolved only when explicitly exported.

For a sheet of n frames with common w,h, c columns (1..n), p padding (0..64), e extrusion (0..16, e<=p), s scale (1..16), rows=ceil(n/c): logical sheet dimensions are `c*(w+2*p)` by `rows*(h+2*p)`. Frame i content starts at `[(i%c)*(w+2*p)+p, (i/c)*(h+2*p)+p]`. All coordinates and dimensions then multiply by s. Every cell has its own border; empty cells remain transparent. Extrusion fills the e-wide ring from clamped nearest content coordinates; transparent source edge pixels stay transparent. Remaining padding transparent. Extrusion does not enter the exported frame rectangle, pivot or collision metadata.

JSON identifies each entry with separate asset/frame fields, integer index, output rect, logical canvas, output/logical pivot, anchors, duration_ms, layer offsets when component export requested, clips and tile contracts. No trimming, packing or rotation. Metadata repeat/playback does not duplicate sheets. Clip indices reference exported entries; if a selected clip references a frame not exported, fail E_REFERENCE instead of inventing an index. Multiple-asset sheets require explicit targets and contain separately qualified clips.

Strict export checks structural integrity, bounds, declared style and selection-specific sheet/clip requirements. It does not force unrelated tile/animation checks on an icon. Color-profile warnings are included in job diagnostics. Export a collection with its shared style applied to every asset; no silent post-render quantization.

### Format correctness and malformed-input requirements

PNG preflight computes exact decompressed byte count, summing nonempty Adam7 pass `(1+rowbytes)*rows`; decoder output must match. Inflate validates reserved BTYPE, length repeat boundaries, required end code, over/under-subscribed trees with RFC-permitted degenerate exceptions, forbidden length/distance symbols and distance<=min(produced,32768). Reject preset dictionary. Distances may overlap; copy byte-by-byte from the growing output/window. Check truncation and stored LEN/NLEN. One zlib stream only. Extra bytes after the zlib stream in final IDAT are ignored with a warning, as allowed by PNG; no concatenated second stream is decoded. IEND must be present; data after IEND is rejected by this subset. Never decompress ancillary text/profile data.

Zlib header requires CM=8, CINFO<=7, FCHECK divisible-by-31 check and FDICT=0. Filter byte stride is max(1,ceil(channels*bit_depth/8)); reset prior scanline to zero at every Adam7 pass. Compare raw grayscale/RGB tRNS samples before expanding sub-byte samples to 8-bit. IHDR/IEND exactly once, PLTE at most once, consecutive IDAT chunks may be multiple/empty, with a valid stream required in aggregate. Header/chunk/tRNS details follow W3C/RFC sources; implementation tests must cite the clause for each disputed edge case. Any unsupported variant gets a precise unsupported error, rather than a generic corrupt-file claim.

## Additional normative boundaries

All public geometry coordinates/offsets are signed i32; positive raster rect sizes are 1..4096. Preflight potential traversal length/area using checked u64 before clipping or loops; i32-range off-canvas endpoints do not authorize unbounded Bresenham work. Mask/region writes consume snapshot source data. A one-color palette always maps to that color, including Bayer4, with no request for a missing second entry.

Edge validation checks label equality on actual map neighbors and structural tile metadata. With tileset `strip-equality=true`, also require identical strips for each complementary label/orientation group; compare each member to one representative, never all pairs. Labels lacking complementary members warn about incomplete transition coverage. Default false: report exact mismatch statistics for requested seam previews or actual map neighbors, but do not fail pixel seam validity. A periodic even-size checkerboard is a valid counterexample to mandatory edge-column equality. Visual seam approval remains external.

F25 Native asset import: inputs source snapshot directory, source asset, destination name; outputs a copied named asset and only needed palette/style dependencies. All layers/cels/timings/clips/pivot/anchors/tile metadata preserved. Equal name/value dependencies reused; unequal collisions fail E_CONFLICT, unchanged. Acceptance: import a layered animated weapon into an independently authored character project, edit it without changing the source snapshot, and export intact metadata. No project merge framework or external linkage.
