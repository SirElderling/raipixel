# Four-perspective adversarial review

The revised proposal was challenged in four separate perspective passes by the revising author. These are design reviews, **not independent external reviewers, certification, application tests or measured usability studies**. Material findings below are resolved in the contracts; remaining empirical risks are explicitly gated.

| Perspective / adversarial finding | Resolution and where to verify |
|---|---|
| Rust systems: a custom recipe, restricted executable manifest and RPX add parsers/formats despite JSON/PNG already being required | One RFC8259 parser, typed JSON jobs, data-only JSON+PNG snapshot; no RPX/custom loader language. Architecture and ADR006/008. |
| Rust systems: PNG import after advanced editing creates a misleading early workflow | Full required DEFLATE and supported real PNG import are S1 dependencies. No static gate without original and imported-art loops. |
| Rust systems: pixel caps alone miss metadata/reference/JSON/clone amplification and hostile off-canvas geometry | Bounded input/nesting/objects/strings/references/work, checked arithmetic, budgeted detach and decoder exact output. Domain/codec malformed cases retained. |
| Rust systems: KISS can be undermined by premature replaceable backend traits | Ordinary module functions with hidden internals and model-owned types; no replacement framework or optional crate backend. ADR020. |
| Graphics: canonical transparent black destroys untouched hidden RGB | Preserve stored samples; alpha key/threshold preserve RGB, copy exact samples; explicit base-copy render gives single-layer PNG sample preservation. Native and external fidelity guarantees separated. |
| Graphics: flat pixels and basic rectangles do not establish original art creation | Foundation compact symbolic grids/palette symbols plus drawing/fill, Core composition/masks/reuse; original-art recognition and held-out asset gate. No claim that these infer missing anatomy. |
| Graphics: format names conceal incompatible state/timing semantics | Format/profile matrix and fidelity output; native full state, PNG samples, OpenRaster supported layers, APNG rendered timing. Animation proposals not treated as OpenRaster baseline. |
| Graphics: exact grid reduction is not automatic grid recovery; edge equality is not seamlessness | Explicit phase required, candidate diagnostics/ambiguity later, irregular-grid repair Deferred; opt-in strip checks and checkerboard counterexample retained. |
| Graphics: frame timing/order/component registration can drift during “small” edits | Named clips, explicit frame durations/pivots/anchors, COW edits, full state/diff tests and scaled independent consumer. No transform implicitly updates anchors. |
| Agent integration: two grammars/substitution/loops increase generation and error surface | One typed JSON contract, structural schema, per-op discovery, JSON Pointer errors, compact grids and explicit batched targets; no custom language. |
| Agent integration: commands can be syntactically valid yet ambiguous or destructive | No current target/wildcards, required owner refs, explicit replace, region/mask scope, pre-operation alias reads and whole-job publication boundary. Unknown and inapplicable fields fail. |
| Agent integration: feedback itself can dominate token use | Target/region inspect, capped histogram with unique-color/truncation counts, optional raw pixels/symbol legend, filtered operation help, small scalar stats/diffs; comparative protocol counts discovery/error/result tokens. |
| Product: independence is not differentiation and “comprehensive” can hide a failing first workflow | Every F01–F25 subfeature classified; first static slice A/B/D/E, first useful toolkit A–E including animation; six controlled comparative tasks, no superiority claim. |
| Product: reducing scope could quietly turn this into an image repair tool | Original creation remains a mandatory artifact/revision gate; animation/components/procedural variations stay Core, layered interchange/tiles remain explicit later product work. |
| Product: interoperability could become a file-extension checklist around private state | Conversion gates and preserved/omitted/converted reports; independent consumers; OpenRaster first planned Advanced interchange increment; public native schema is not called an external standard. |

The consistency pass also found two preservation traps: optional content-deduplication could destabilize canonical save/load bytes, so baseline serialization follows shared allocations deterministically; and arbitrary OpenRaster decimal opacity cannot be represented exactly by u8, so explicit conversion/fidelity reporting replaces a blanket lossless-opacity claim. Hidden binary helper layers are exempt from the asset display-palette constraint while visible rendered frames remain checked.

## Consistency checks before publication

Check every command example structurally against the committed schema, then review cross-field geometry, source/owner order and prerequisite snapshots. Confirm sword grid dimensions and changed-pixel counts, animation timings, untrimmed sheet formulas and scaled anchors. Check local Markdown links/fences, requirement-ID coverage, priority consistency, prohibited project identities and documentation-only diff. These checks establish internal document consistency, not that an application executed them.

Any critical finding discovered by those checks must be fixed in all affected contracts before publication. Foundation/Core feature completion, cross-platform decoder correctness, actual LLM recognition/correction efficiency, format consumer behavior and performance remain unresolved implementation/validation work with named gates in the roadmap and acceptance catalogue.
